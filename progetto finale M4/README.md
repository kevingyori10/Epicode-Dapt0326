# Progetto finale Modulo 4 

## Scenario
Analisi delle vendite di un'azienda di giocattoli e articoli outdoor che vende tramite rivenditori in 9 paesi europei (2023-2025).

## Task
1. Python di base
2. Lettura e ispezione dei dati
3. Pulizia, merge, groupby e serie temporali
4. Grafici
5. Regressione lineare
6. Churn con regressione logistica e segmentazione con K-Means
7. Debugging e refactoring

## File
- progetto_finale_M4.ipynb: il notebook
- 4 file di dati: products.csv, sales.json, regions.xlsx, resellers.csv

## Come eseguirlo
1. Scaricare tutti i file nella stessa cartella
2. Aprire il notebook con Jupyter (Anaconda)
3. Run → Run All Cells

Librerie: pandas, numpy, matplotlib, seaborn, scikit-learn
